# 知識をためて使う

[[obsidian/knowledge/ホーム|ホーム]] · [[obsidian/knowledge/views/知識一覧.base|知識一覧]]

## 書く → つなぐ → 使う

1. `Ctrl+N` でメモを作り、思いついたことを書く。名前や分類はあとで直せる。
2. 関係する言葉に `[[` を入力して、既存ノートを選ぶ。バックリンクで逆方向からもたどれる。
3. 調査・実験・判断として残したくなったら、`Ctrl+Alt+T` でテンプレートを挿入する。
4. 資料を見たら、URLまたは元ノートへのリンクと、自分の理解を分けて書く。
5. 次の設計・実験・説明で、ノートをリンクするか、`![[ノート名]]` で埋め込んで使う。

分類やプロパティは任意。文章だけのノートも一覧の「最近のノート」と「未整理」に出ます。未作成のアイデアへリンクしておき、あとで中身を書く使い方もできます。

## 保存先

| 保存先 | 使い方 |
| --- | --- |
| `private/00_Inbox/` | 新規ノートの既定先。思いつき・疑問・未整理のメモ |
| `private/10_Notes/` | 自分用の知識、AquaBeacon以外の学びも可 |
| `private/20_Sources/` | 論文・記事・資料を読んだ記録 |
| `private/30_Experiments/` | 実験メモ、結果への参照、次に試すこと |
| `private/40_Decisions/` | 採用案・代替案・判断理由 |
| `private/50_Journal/` | 日誌。`Ctrl+Alt+D` で今日のノートを開く |
| `private/90_Attachments/` | 貼り付けた画像・添付の既定先 |
| `notes/` | 共有するために整えた知識 |
| `maps/` | 関連ノートを束ねる索引。複数の索引から同じノートへリンクできる |

`private/` はGitで除外しています。公開したいノートだけ、内容と出典・添付の権利を確認して `notes/` へ移します。共有ノートから個人用の資料や添付へリンクした場合は、他の人が参照できる出典へ置き換えてください。生データ・認証情報・購入台帳の扱いは各プロジェクトの規約に従います。

## 型を選ぶ

| テンプレート | 残すもの |
| --- | --- |
| [[obsidian/knowledge/templates/メモ\|メモ]] | 一言、疑問、思いつき |
| [[obsidian/knowledge/templates/知識\|知識]] | 何度も使う結論と適用条件 |
| [[obsidian/knowledge/templates/調査\|調査]] | 出典、要約、自分の解釈、残った問い |
| [[obsidian/knowledge/templates/実験\|実験]] | 仮説、条件、入力、結果、限界、再現方法 |
| [[obsidian/knowledge/templates/判断\|判断]] | 選択肢、採用理由、再検討する条件 |
| [[obsidian/knowledge/templates/日誌\|日誌]] | その日の学びと関連ノート |

テンプレートは空のノートへ挿入します。書きかけのメモへ使うときは、必要な見出しだけコピーしても構いません。

## 一覧・検索・関係図

[[obsidian/knowledge/views/知識一覧.base|知識一覧]] は追加したノートを自動で拾います。テンプレートは除外し、最近のノート・未整理・知識・調査・実験・判断・日誌・共有ノートのビューを用意しています。

標準検索（`Ctrl+Shift+F`）では、次のように探せます。

```text
path:obsidian/knowledge 音速
path:obsidian/knowledge/private
path:obsidian/knowledge [kind:experiment]
path:obsidian/knowledge [status:draft]
```

`Ctrl+O` でノート名から移動できます。グラフは最初は知識フォルダを中心に表示します。グラフの検索条件を外すと、元の設計書とのつながりも確認できます。

[[obsidian/knowledge/知識マップ.canvas|Canvas]] は分野同士の関係を示す出発点です。カードを動かしたり追加したりして自由に編集できます。新しい考えを試すCanvasは `private/` に作れます。

## プロパティは揃えたいときだけ

| プロパティ | 値の例 |
| --- | --- |
| `kind` | `note`, `concept`, `source`, `experiment`, `decision`, `journal`, `map` |
| `status` | `inbox`（未整理）, `draft`（検討中）, `evergreen`（繰り返し利用）, `archived` |
| `created` | 作成日。テンプレートで自動入力 |
| `topics` | 関連分野やノートへのリンクのリスト |
| `projects` | 関連リポジトリ名のリスト |
| `sources` | 根拠にした資料のリンクやURLのリスト |
| `tags` | 横断して探すためのキーワード。初期値は `knowledge` |

`status` はノートの整理状態です。実機動作・精度・製造の検証結果は本文に条件付きで記録します。日付もノートの作成日と根拠資料の改訂日を分けます。

## 元資料と一緒に育てる

既存の仕様や解析レポートは各リポジトリの正本をリンクします。知識ノートに全文をコピーせず、「何が分かったか」「どの条件で使えるか」を書きます。仕様を変えるときは元の設計書と実装も更新します。

[[obsidian/knowledge/notes/設計資料は改訂と対象を照合する|資料の読み分け]]を参照してください。`private/` と `.obsidian/` はGitに保存されないため、長く使う個人メモと設定は自分のバックアップにも含めます。
