# AquaBeacon 知識のホーム

気づきを残す → 必要なときに探す → 関連をつなぐ → 設計や実験に使う。

> [!tip] まず書く
> 新規ノートは `obsidian/knowledge/private/00_Inbox/` に入ります。ひとことだけでも大丈夫です。`[[` で関連ノートを選ぶだけで、知識のつながりが増えます。

## いま使う

| やりたいこと | 入口 |
| --- | --- |
| メモを書き始める・検索方法を知る | [[obsidian/knowledge/使い方\|使い方]] |
| ためた知識を探す | [[obsidian/knowledge/views/知識一覧.base\|知識一覧]] |
| 関係を並べて考える | [[obsidian/knowledge/知識マップ.canvas\|知識マップ]] |
| 元の仕様・実装を探す | [[obsidian/knowledge/リポジトリ一覧\|リポジトリ一覧]] |
| 今日の記録を残す | Daily notes（`Ctrl+Alt+D`） |
| 型を使って書く | Templates（`Ctrl+Alt+T`） |

## 書き方は必要になってから

自由メモはそのまま置いておけます。繰り返し使いたくなったら、結論・出典・適用条件を足して独立したノートへ。分類が増えたら、関連する分野の索引からリンクを足します。AquaBeacon以外の学びも、同じ仕組みで残せます。
