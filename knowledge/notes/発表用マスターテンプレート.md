## 決定した配色と文字

ユーザーの意図は、**基本色を2〜3色に絞り、その各色から派生する濃淡を多く用意する**こと。多数の異なる色相を並列に増やす設計でも、青1色だけに限定する設計でもない。

| 項目 | 設定 |
| --- | --- |
| 基本の青 | `#006C80`。普段の説明・主系列 |
| オレンジ | `#B85A18`。比較や強調 |
| 緑 | `#2E7655`。別の対象・分類 |
| 濃淡 | 各色8段階、計24色。淡色は主に面・範囲・背景に使う |
| 背景・本文 | 白`#FFFFFF`、濃い本文`#1B272D`、補助文字`#46555E` |
| 日本語 | BIZ UDPゴシック。本文Regular、見出しBold |
| 英数字 | Segoe UI |
| 文字サイズ | 本文・図中文字28pt以上、タイトル32pt |
| スライド寸法 | 16:9、960×540pt（33.87×19.05cm） |
| 見出し | 本文面積を確保するため、太いタイトル帯を使わず細い罫線で区切る |

毎ページ3色すべてを使う必要はない。グラフなどで濃淡が近い場合は、直接ラベル・線種・点形状も併用する。原資料への忠実な追従より、このチャットで決めた配色・サイズ・広い本文領域を優先する。既定のAquaBeacon手作り作風からの変更は、ユーザーが明示的に認めたもの。

PowerPointのアクセント1〜3に各基本色、4〜6に各濃色を設定し、カスタム色に全24色を保存。色選択欄の表示がOfficeのバージョンで異なる場合は、見本の図形からスポイトかHEX指定で使える。

## 使い方と適用条件

`.potx`を開いて新しい発表資料を作る。タイトル入り版は、表紙を開始ページに持ち、「タイトル｜写真と3色」「見出し＋本文」「見出し＋自由配置」「白紙」の4レイアウトを含む。本文用の版は後者3レイアウト。

表紙の写真を含む構成を再利用する場合は開始ページを複製する。新しくタイトルレイアウトを挿入した場合は、写真を別途入れる。文字はネイティブのプレースホルダー／テキスト、写真は編集可能なスライド画像。写真は元の未踏成果報告会資料の第1枚を使用し、題名・会議名・所属氏名もその資料を基にしている。別の発表では内容や氏名・所属をその都度変更する。

自動文字縮小は無効。マスターの初期値は、手動変更や画像内の小さな文字を禁止する機能ではない。スクリーン幅は不明のため6mを想定して検討したが、28pt／32ptで50m先からの可読性を保証したものではない。投影時は最後列で確認する。

PowerPointでPPTXと保存後POTXを開いて表示を確認済み。本文28pt・見出し32pt、4レイアウト、カスタム24色の保持を検証している。元の発表資料は変更せず、公開・外部アップロードも行っていない。

## 旧版との区別

`.local/presentation-theme-20261105/`、同`-v2/`、同`-v3/`は検討途中の履歴。大きすぎる文字サイズ、多色相の12色、青1色の濃淡などを含むため、現行の配色・文字設定の基準にしない。本文の確定版は`-v4/`、その設定にタイトルを追加した現行版は`presentation-cover-20261105/`。

## 発表原稿の書き方（2026-11-07追記）

出典：2026-11-06のユーザー指示「文が短すぎて不自然」「1文80文字までを上限」、および2026-11-07の知識・スキルへの保存依頼。発表原稿に適用し、画面の見出しや一般の文章に一律適用しない。後の明示指定を優先する。

- 一息で読めることを、細切れの短文に置き換えない。原因と結果、対象と説明を自然につなぎ、1文80文字以内にする。上限まで伸ばす必要はなく、必要な短文も残す。
- 主語・述語・接続を整え、測定値、条件、不確実性を保つ。句読点・かぎかっこ込みで文長を確認し、空白や演出指示は除外する。
- 指定された持ち時間に合わせ、読み上げ、動画、間、切替を計算する。動画中の説明は二重計上しない。読む速さの仮定と、リハーサル実測ではないことを明記する。
- 今回は13分枠に対して、本編3,592文字、1文最大66文字、毎分300文字で約12分35秒と見積もった。毎分295〜305文字では約12分23秒〜12分47秒。別の発表にも13分を固定適用しない。
- 原稿だけの修正はPowerPointの発表者ノートを対象にし、スライド・図・動画を保つ。別の原稿ファイルや時間表があれば同期する。
