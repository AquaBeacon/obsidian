# 光と音とテザーの役割

AquaBeaconの基本構成では、音で親子機間の距離、光で方向、テザーで測距イベントの同期を扱う。異なる観測を組み合わせて子機位置の推定につなげる。

| 要素 | 役割 | 一緒に確認する条件 |
| --- | --- | --- |
| 音響 | 伝搬時間を距離へ換算する | 音速、固定遅延、受信判定 |
| 光学 | 親機カメラから見た子機ライトの方向を求める | 内部校正、取付姿勢、水中での条件 |
| テザー | 送受信イベントを対応させる | 使用回線、同期方式、遅延 |
| GNSS・IMU・圧力 | 位置基準、姿勢、深度などを与える | センサ位置、時刻、座標系 |

これは各資料を読むための役割整理。SBL派生案など別構成を読むときは、対象システムと実装版を確認する。
